# 禅 v1.0.1

## Highlights

- 首页升级为可滚动的分类菜单，新增“禅趣、静心、创作、记录”四个分区；在 `200×200` 小窗口中也能访问全部功能。
- 新增赛博念珠、莲花呼吸、入定计时、数字枯山水、电子颂钵与修行簿，应用现包含九种互动与记录体验。
- 呼吸、入定、颂钵音效全部由 Web Audio 实时合成，不包含外部音频素材。

## Improvements

- 赛博念珠支持点击或拖动逐颗拨动，四轮共 108 念时触发圆满光环与提示音，之后仍可继续累计。
- 莲花呼吸提供 1、3、5 分钟选项，按 4 秒吸气、6 秒呼气引导；入定计时提供 5、15、25、45 分钟及可选棕噪音。
- 数字枯山水支持耙沙、置石、撤销、清空、保存、恢复与导出 PNG。
- 电子颂钵支持点击敲击和沿钵缘绕行，速度会影响泛音和光晕。
- 修行簿汇总今日、最近 7 天、累计数据与温和里程碑，同时保留原有木鱼、烧香和竹知了记录。
- 前端拆分为共享导航、样式和独立功能模块；本地脚本与 CI 会自动同步唯一的 `public/` 源码到 fnOS 包。

## Fixes

- 新增 `practice.json` 与 `garden.json` 持久化，念珠、计时、沙庭和颂钵记录在 Windows、Linux、macOS 与 fnOS 使用各自应用数据目录保存。
- 计时采用绝对结束时间，关闭应用或跨日期后可恢复并自动结算；重复完成请求不会重复累计。
- 活动写入增加幂等请求 ID，JSON 文件采用原子替换，降低重试或异常退出导致重复、丢失和文件损坏的风险。
- 离开电子颂钵或入定页面时会立即停止持续声音和余音。

## Upgrade Guide

- 可直接从 v1.0.0 升级；现有 `counts.json`、`incense.json` 与 `cicada.json` 会原样保留，不迁移也不清空。
- fnOS 安装或升级时继续使用应用数据目录，服务端口仍由安装向导指定。
